# Price Manager - Star Computación

## Sprint 1

### Objetivo
Desarrollar una aplicación de consola (CLI) robusta en Python que permita
gestionar el inventario de un local de hardware, cotizar productos en tiempo
real según el valor del dólar y comparar precios con la competencia web.

### Introducción y Contexto del Sprint
Una empresa distribuidora de productos electrónicos necesita modernizar su
sistema de gestión de inventarios. Debido a la volatilidad económica, el sistema
debe gestionar precios en diferentes monedas y seguir de cerca la cotización
del dólar para actualizar sus valores en tiempo real.
